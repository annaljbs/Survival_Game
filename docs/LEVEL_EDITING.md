# Editing the level by hand (Tilemaps, prefabs, Scene view)

The first levels were generated by code (`Survival > Build Greybox Scene`). That is good for testing, but not for level design.
**Survival > Make Level Editable (one time)** turns it into a normal Unity scene you edit like in any other project.

## 1. Make the level editable (once)

1. Wait until Unity has finished compiling.
2. Menu **Survival > Make Level Editable (one time)**. It takes a moment.
3. It creates and opens nothing new for you to fix; it saves **`Assets/Scenes/Level.unity`** and makes it the scene in Build Settings.
4. Open `Assets/Scenes/Level.unity`. This is now *your* level. Do not use the generator on it (the generator refuses to run in `Level.unity` to protect your work).

What was created:

| Where | What |
|---|---|
| `Assets/Scenes/Level.unity` | the level (root object `LEVEL`) |
| `Assets/Tiles/` | Tile assets: dirt, trees (and mirrored trees) |
| `Assets/Prefabs/Objects/` | one prefab for each kind of object (seats, magazines, spruce, green bush, pickups, ...) |
| `Assets/Resources/Pixel/...` | the pictures, now cut into real sprites (open one in the Sprite Editor to see the pieces) |

## 2. The level in the Hierarchy

- **Ground**: the grass base, made of 36 tiled pieces of 40 x 30 tiles (`Ground piece`). Do not make it one huge picture: Unity cannot draw more than about 16000 tiles in one sprite. If you see the error "Cannot generate 9 slice ... size is too big", run **Survival > Fix Ground (split into pieces)** and save.
- **Grid: Paths / Details / Trees**, each with a **Tilemap**:
  - **Paths** (cell 1): the dirt roads.
  - **Details** (cell 1, empty): for your own flowers, rocks, patches.
  - **Trees** (cell 2): one 32x32 tree per cell. **It has a collider: a painted tree blocks the way, an erased tree is open ground.** To make a new path, erase trees; to close a way, paint trees.
- Objects (wreck items, bushes, spruce, camps, pickups, find spots, terrain zones, labels), the **Player** and **Systems**.

## 3. Painting tiles (Tile Palette)

1. **Window > 2D > Tile Palette**.
2. **Create New Palette** (name "Forest", Rectangular), save it in `Assets/Palettes`.
3. Drag into the palette window:
   - the tiles from `Assets/Tiles` (trees, dirt), and/or
   - whole sheets from `Assets/Resources/Pixel/Tilesets` (`TilesetFloor`, `TilesetNature`, `TilesetWater`, `tileset_camp`). Unity makes a tile for every piece. Pick a folder for the new tile assets (for example `Assets/Tiles/Generated`).
4. In the palette window choose the **Active Tilemap** (Paths, Details or Trees) and paint: **B** brush, **U** box fill, **I** pick, **D** erase (or Shift+click with the brush).
5. Use `Trees` only for trees you want to block the way. Use `Details` for things you can walk over.

Sprite names: `TilesetNature_3_10` = column 3, row 10 of that sheet (16x16 pieces counted from the top-left). `TilesetNature_r0_0_32x32` = a bigger piece (x, y, width x height in pixels from the top-left), for example a tree.

## 4. Objects (items, chairs, magazines, ...)

- Drag a prefab from `Assets/Prefabs/Objects` into the Scene. Move **W**, rotate **E**, scale **R**, duplicate **Cmd+D**.
- Changing a **prefab** (double-click it) changes all objects of that kind. Changing one object in the scene changes only that one (use Inspector overrides).
- **Interactable** component: Action = name, minutes, energy/water/food/warmth, requirements, gives, ... (see `docs/TUNING.md`).
- **Picture of an object**: select it, in **Sprite Renderer** click the sprite circle and search a name (for example `Letter`, `TilesetCamp_`, `Bag`). Set the **Draw Mode** to Tiled to repeat a picture (water).
- Put your own PNG into `Assets/Resources/Pixel/Custom` (it becomes one sprite automatically) and pick it the same way.

## 5. Things to know

- **Random finds:** the pickups and clothes move to random **Find spot** objects at the start of each run. Add spots by duplicating a `Find spot (ground)` or `Find spot (tree)` object and moving it.
- **Camps:** a camp is the objects named `Camp X ...`, the `Zone: Camp X` and the `Fire pit: Camp X`. To make a new camp, select all objects of one camp together, duplicate them together (Cmd+D) and move them; the links between them are kept. Give the zone its own **Site Name** and **Note**.
- **Sorting order** (Sprite Renderer): ground -50, paths -44, details -43, water -20, trees 1, objects 5, player 10. Keep objects at 5 or above so they are drawn over the trees and the ground.
- **Map edge:** the invisible `Wall` objects at x = ±120, y = ±90 keep the player in. Move them if you make the map bigger, and extend the ground (`Ground` object, Size).
- **Rain, night, thoughts, sounds** work as before; nothing needs to be set up for them.
- Save with **Cmd+S** and commit often (the scene is the only copy of your design).

## 7. A bigger Scene view

- **Shift + Space** with the mouse over the Scene view makes it fill the whole window; press it again to go back. Best while painting.
- Drag the thin lines between the panels to give the Scene view more room (for example make the Game view and the Console small).
- Close the **Game** tab while designing (right click the tab > Close Tab; open it again with Window > General > Game), or drag it under the Scene view.
- A good painting layout: Scene view big in the middle, **Tile Palette** docked on the right, Hierarchy on the left, Inspector next to the palette. Save it with the **Layout** menu (top right) > **Save Layout...** and switch back with it at any time.
- Navigate: scroll wheel = zoom, **Q** (hand) + drag = move, **F** = frame the selected object, middle mouse drag also moves.

## 8. Do the colliders still work when I change tiles?

Yes. The collider of the `Trees` tilemap is rebuilt by Unity every time you paint or erase (the shapes are merged into one).
What counts is the tile's own **Collider Type** (select the tile asset in `Assets/Tiles`):

| Collider Type | Effect |
|---|---|
| **Grid** | the whole cell is solid (a 2 x 2 box). The tree tiles use this. Changing the picture of the tile does not change the collider |
| **Sprite** | the collider follows the outline of the picture (tight around the tree). This is the default for tiles Unity makes from a sheet |
| **None** | the tile does not block, even on the `Trees` tilemap |

- Only the **Trees** tilemap has a collider. Tiles on `Paths` and `Details` never block. To make a new blocking decoration (rock, wall), paint it on `Trees`, or add another Tilemap with a **Tilemap Collider 2D**.
- If you make a new tile from a sheet and want it solid, set its Collider Type to Grid (or Sprite).
- Tiles bigger than their cell (a 32x32 tree on a cell of 2) overlap their neighbours visually. The collider stays inside the cell with Grid.

## 9. Fewer trees: remove what the camera never sees

**Survival > Trim Hidden Forest (camera never sees it)** deletes the trees and ground pieces that are too far from any place the player can walk to ever be on screen (about 16 units sideways and 10 up and down, enough for wide windows). On the first map this removes about 60% of the trees.
- It finds the walkable area by flood fill from the Player, so it works after you changed the forest by hand. Keep the Player on open ground.
- It asks first and tells you the numbers; **Cmd+Z** undoes it.
- The forest ring next to every path and clearing stays, so you never see an empty edge while playing. If you open a new area later (erase trees, move the Player there and run it again), nothing you built is removed, only unreachable and unseen forest.
- Run it again after you made the walkable area smaller or removed paths.
- **Make Level Editable** runs it automatically.

## 6. If something is off

- **"The referenced script (Unknown) on this Behaviour is missing!"**: run **Survival > Repair Find Objects (missing scripts)** in the open scene, then Cmd+S. (Cause, fixed in the code: the scripts `RandomFind` and `FindSpot` were in the wrong file. In Unity every component script must be in a file with the **same name as its class**, one component per file.)

- A picture is missing on an object: the console shows `Make Level Editable: no sprite for ...`. Pick a sprite by hand (see 4).
- To start the editable level again from the generator: run **Make Level Editable** again. This **replaces** `Level.unity` after asking (your manual changes are lost).
- The old generated test level is still `Assets/Scenes/landscape.unity` (Survival > Build Greybox Scene works there).
